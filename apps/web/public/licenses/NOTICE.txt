LensDock web UI - third-party font and library notices
=======================================================

The LensDock web UI bundles the font files below so that the interface and the
annotation PNG export render identically on machines that have none of these
fonts installed, and without contacting a third-party CDN. The fonts are
redistributed unmodified as WOFF2 files produced by the Fontsource project
(https://fontsource.org). Each family is licensed under the SIL Open Font
License, Version 1.1; the full text accompanies this file (OFL-*.txt). The
Font Software is not sold by itself, and no Reserved Font Name is used for a
modified version.
